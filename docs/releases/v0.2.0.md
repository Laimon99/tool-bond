# BondFX v0.2.0 — public proof of concept

BondFX is now publicly available as an educational, end-to-end valuation demo
for a TRY-denominated bond translated into USD through an explicit FX-forward
curve.

## Highlights

- guided manual valuation and synthetic Excel-import flows;
- transparent cash-flow, FX-conversion and discounting breakdown;
- independently checkable financial example;
- versioned JSON contracts, FastAPI documentation and reproducible containers;
- public CI, dependency auditing, security policy and protected `main` branch;
- hosted demo with static assets on Cloudflare and the full FastAPI/Excel
  workflow on Render Free.

BondFX is educational software. It is not investment advice, a market-data
source, an executable quote or a production pricing library.

## Quick start

Run the hosted demo from the repository homepage, or start it locally with:

~~~text
docker compose up --build
~~~
